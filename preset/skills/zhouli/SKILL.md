# 《周礼》检索与引证

`zhouli` 工具提供《周礼》全文的结构化检索，每条结果都带**稳定坐标**，可供引证与复核。

**凡需引用《周礼》原文，一律用这个工具查，不要凭记忆背诵。** 编造或凭印象转写的引文，
比不引更糟。

## 坐标系统

每段有稳定坐标 `篇序.职官序`：

| 篇序 | 篇名 | 职官数 |
|---:|---|---:|
| 1 | 天官冢宰 | 63 |
| 2 | 地官司徒 | 78 |
| 3 | 春官宗伯 | 70 |
| 4 | 夏官司馬 | 70 |
| 5 | 秋官司寇 | 66 |
| 6 | 冬官考工記 | 30 |

- `.0` 是该篇「叙官」，列出全部官职的员额编制；
- `.1` 及以下是各官职的职掌条文。

例：`1.1` 是〈大宰〉，`1.2` 是〈小宰〉，`3.21` 是〈大司樂〉，`6.1` 是〈輪人〉。

引证格式：**《周礼·天官冢宰》1.1** —— 篇名用繁体篇名，坐标紧接其后。

## 工具用法

```
zhouli(action, query?, coordinate?, chapter?, limit?)
```

| action | 用途 | 参数 |
|---|---|---|
| `search` | 全文检索（繁体优先，简体兜底） | `query` 必填；`chapter`、`limit` 可选 |
| `para` | 按坐标取一段原文（繁体＋简体对照） | `coordinate` 必填，形如 `1.1` |
| `zhiguan` | 查某官职的员额编制与职掌 | `query` 为职官名；省略则列出全部；`limit` 可选 |
| `list` | 列出某篇（或全部）的职官名 | `chapter`、`limit` 可选 |
| `chapter` | 列出某篇的段落原文 | `chapter` 必填；`limit` 可选 |
| `jiaokan` | 查勘记：底本与郑玄注本之异文 | `coordinate`（查某段）或 `query`（查某句）或 `chapter`（列某篇）；皆省则报各篇之数 |
| `stats` | 语料库规模与底本来源 | — |

`chapter` 接受繁体篇名、简体篇名或序号 1–6，三者等价。

## 查异文（非可选）

语料库附有 Kanripo 两本（正文与鄭玄注本，四部叢刊本）之互校勘记，凡 **567 条**。
**引一句之前，当先知其有无异文**：两本有出入而径引一本、不作说明，即是失真。

三条路，任取其一：

1. `zhouli(action:"jiaokan", query:"你要引的那一句")` —— 报该句所在区间有无异文；
   给 `coordinate:"6.0"` 则查该段全部异文；只给 `chapter` 则列某篇之异文；皆不给则报各篇之数。
2. 若所装版本尚无 `jiaokan` 动作，读 `data/text/周礼.校勘记.txt`（人可读，逐条列上下接文）。
3. 或读 `data/jiaokan.json`（逐条含 `pos`、`底本`、`异本`）。

本技能引文库六条之中，**唯 6.0 一条立于异文之上**：
底本作「審曲面**埶**以飭五材」，郑玄注本作「審曲面**执**以飭五材」
（`data/text/周礼.校勘记.txt` 两处并载）。引此句可取底本之「埶」，但须知此处有异文，
两本之别不可抹去；余五条两本全同，可径引。

## 工具不可用时的退路

若 `zhouli` 工具不在工具列表中（`dsh-zhouli` 包未安装，或该会话的 profile 未挂载它）：

1. 明确说明「未能核实《周礼》引文」；
2. 不要把凭记忆写出的句子当作原文引用，也不要用「据《周礼》」含糊带过；
3. 如确需引用，标注该句**未经核实**，并说明它可能不准。

**未核实的引文不构成背书。** 宁可少引一条，不可虚引一条。
